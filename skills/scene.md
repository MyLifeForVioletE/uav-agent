# 场景构建技能

当用户要求构建、生成电磁场景时，你需要从用户的自然语言描述中提取以下实体类型的结构化数据。

## 实体类型

系统会向你注入完整的字段定义。以下是各实体类型的概要和层级关系：

### carrier（载体）
载体装备信息，包含标识、位置坐标、运动状态、阵营、时间参数等。
- 用户通常描述为：某型无人机、飞机、车辆、舰船等平台

### equipment（装备）
载体上安装的装备信息，包含标识、功率、天线参数、馈线损耗、工作状态等。
- 用户通常描述为：雷达载荷、通信设备、干扰设备、侦察接收机等
- equipment 下可嵌套：
  - `equipment_model`（struct）：装备模型完整参数，含收发频率、功率、调制、接收机性能等
  - `equipment_radar_extd`（array）：雷达装备扩展参数
  - `equipment_radio_extd`（array）：通信装备扩展参数
  - `equipment_interference_extd`（array）：干扰装备扩展参数
  - `equipment_model_radar_extd`（array）：雷达模型扩展参数
  - `equipment_model_radio_extd`（array）：通信模型扩展参数

### antenna（天线）
天线参数，包含类型、增益、波束宽度、极化方式、方向图等。
- 用户通常描述为：全向天线、定向天线、抛物面天线等
- antenna 下可嵌套：
  - `水平天线方向图`（array）：各水平角度的增益/损耗
  - `垂直天线方向图`（array）：各垂直角度的增益/损耗

### project（项目）
仿真项目信息，包含标识、时间范围、区域矢量等。
- 用户通常描述为：仿真项目名称、时间范围、区域范围等
- project 下可嵌套：
  - `project_vector`（array）：项目区域矢量（航线、边界等）
  - `project_vector_extd`（array）：矢量坐标点（经纬度、高度等）

### work（工作参数模板）
装备工作参数，包含收发频率、天线角度、功率、调制方式等。
- 用户通常描述为：工作频率、功率、调制方式等具体参数

## 提取规则

1. **只提取用户明确提到的字段**，未提及的字段不要猜测，留空或省略
2. **嵌套结构要完整**：如果用户提到了装备的型号参数，应放入 `equipment_model` 子对象
3. **数组用列表**：同类多条数据（多个方向图点、多个坐标点）作为数组元素
4. **字符串用双引号，数值不加引号，布尔值用 true/false**
5. **禁止编造参数**：不要凭空捏造用户未提供的技术指标

## 输出格式

严格输出 JSON，用 ```json 代码块包裹，不要附加任何解释文字。

```json
{
  "carrier": [
    {
      "载体名称": "...",
      "经度": 116.4,
      "纬度": 39.9
    }
  ],
  "equipment": [
    {
      "装备名称": "...",
      "equipment_model": {
        "模型名称": "...",
        "发射频率下限": 1000,
        "发射频率上限": 2000
      },
      "equipment_radar_extd": [
        {"调制方式": "..."}
      ]
    }
  ],
  "antenna": [...],
  "project": [...],
  "work": [...]
}
```

## 完整流程

1. 用户描述电磁场景（如："一架无人机搭载雷达载荷，在城市区域执行巡检"）
2. 你根据上述规则提取结构化 JSON
3. 系统自动将 JSON 分发到 15 张 Excel 表并生成场景文件
4. 你告知用户场景文件已生成
