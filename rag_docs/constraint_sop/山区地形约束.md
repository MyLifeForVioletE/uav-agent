# 山区地形约束

level:constraint_sop
constraint:mountainous_terrain

## 触发条件
任务区域为山区、丘陵或起伏地形

## 规划时应考虑的因素
- 地形落差对航线可行性和安全间距的影响
- 山体对无线通信链路的遮挡风险
- 起降区域的地形平坦度和障碍物分布
- 地形变化对飞行姿态稳定性的潜在干扰
- 地形高程数据的可获取性和精度

## 原子动作拆分时的参考
- 在规划航线类动作时，考虑将地形高程数据纳入航线验证
- 在规划航线类动作时，考虑检查航线与地形的安全间距
- 在规划飞行类动作时，考虑地形变化对飞行姿态的影响
- 在规划通信类动作时，考虑评估地形遮挡的可能性
