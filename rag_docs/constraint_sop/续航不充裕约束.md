# 续航不充裕约束

level:constraint_sop
constraint:low_endurance

## 触发条件
任务续航余量紧张或电池容量有限

## 规划时应考虑的因素
- 往返总飞行距离与电池容量的匹配关系
- 安全返航所需预留的电量余量比例
- 环境温度对电池实际放电能力的衰减影响
- 不同飞行速度和机动动作对功耗的差异
- 任务执行中电量消耗节奏的可观测性

## 原子动作拆分时的参考
- 在规划航线类动作时，考虑将续航余量作为路径优化的约束条件
- 在规划自检类动作时，考虑关注电池状态和功耗参数的核查
- 在规划飞行类动作时，考虑是否需要加入续航状态的持续监测
- 在规划返航决策类动作时，考虑将电量余量作为安全判断依据
