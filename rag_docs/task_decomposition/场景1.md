# 场景：单机定点侦察

## 任务描述
使用一架侦察无人机到目标位置侦察敌方的一个通信目标。期望得到敌方通信目标的频率、带宽、信号强度信息。该目标通信使用的频率在1GHz~2GHz范围内。

## 子任务分解

```json
{
    "scenario": "一架无人机到目标位置侦查一个敌方目标",
    "uav_count": 1,
    "sub_tasks": [
        {
            "task_id": "T1",
            "task_name": "无人机飞抵目标位置执行扫频侦察",
            "goal": "飞行至目标位置并获取敌方通信目标在侦察位置处的扫频数据",
            "executor": "uav",
            "assigned_uav_role": "scout",
            "prerequisite_tasks": [],
            "constraints": []
        },
        {
            "task_id": "T2",
            "task_name": "信息处理agent分析目标的扫频数据，得到敌方目标的频率，带宽，信号强度",
            "goal": "获取敌方通信目标的频率、带宽、信号强度信息",
            "executor": "info_processor",
            "assigned_uav_role": null,
            "prerequisite_tasks": ["T1"],
            "constraints": []
        }
    ]
}
```

## 分解要点（必须遵守）
- "飞行至目标位置"属于侦察动作的一部分，**不能**单独拆成一个子任务，必须并入采集子任务（如上 T1 的 goal 同时包含"飞行至目标位置"和"获取扫频数据"）。
- 采集(uav)与分析(info_processor)按执行主体不同拆开，分析子任务在 prerequisite_tasks 中依赖采集子任务。
- 不要在输出中出现只描述"飞行/前往/返航/抵达"而没有信息产出的子任务。
