# 场景：双机协同侦察+干扰压制

## 任务描述
使用两架侦察无人机分别到两个不同位置侦察敌方的一个通信目标。期望得到敌方通信目标的频率、带宽、发射功率信息。该目标通信使用的频率在1GHz~2GHz范围内。根据侦察信息确定实施干扰的位置，对敌方目标实施干扰压制。

## 分解要点（必须遵守）
- "飞行至目标位置/位置1/位置2"属于侦察动作的一部分，**不能**单独拆成一个子任务，必须并入对应的采集子任务（如上 T1/T3 的 goal 同时包含抵达位置与获取扫频数据）。
- 不要输出只描述"飞行/前往/返航/抵达"而没有信息产出的子任务。
